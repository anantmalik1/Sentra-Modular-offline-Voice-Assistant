## 🌌 ✨ About Sentra

💡 **Sentra AI** is a next-generation voice assistant that can:

* 🎤 Understand voice commands
* 🌐 Control apps & browser
* 📩 Send messages automatically
* 🎵 Play music on YouTube
* 🧠 Use AI to think & respond
* ⚡ Perform real-world automation

## 🧠 💥 Core Features
